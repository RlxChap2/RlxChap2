<h1 align="center">Mohammed Mahmoud</h1>

Software engineering student at Assiut University, Egypt. I build backend services in TypeScript and desktop apps in Rust.

## Projects

- [MediaFilez Desktop](https://github.com/MediaFilez/mediafilez-desktop): Download public videos, images, and audio on Windows.
- [MediaFilez](https://github.com/RlxChap2/MediaFilez): Download media into Discord with a single `/media` command.
- [Bonyan API](https://github.com/BonyanOSS/Bonyan-API): Quran, hadith, and prayer-time API with a [JavaScript and TypeScript SDK](https://github.com/BonyanOSS/bonyan-sdk-js).
- [ContribScope](https://github.com/RlxChap2/contribscope): Generate contributor avatar grids across GitHub repositories.
- [MASC-256](https://github.com/RlxChap2/MASC-256): Experimental authenticated stream cipher in C, for research.
